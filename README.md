# Software Design (Diseño de Software) - UDC Engineering
This repository contains the complete set of assignments for the Software Design course, covering everything from OOP foundations to advanced Design Patterns and SOLID principles.

## 📂 Repository Structure
- **/P1 - Fundamentals**: Java basics, Logic, and Unit Testing (JUnit 5).
- **/P2 - Advanced OOP**: Inheritance, Polymorphism, Generics, and UML Modeling.
- **/PD - Design Patterns**: Implementation of structural and behavioral patterns (Observer, State, Strategy) and SOLID compliance.

## 🛠 Tech Stack & Tools
- **Language**: Java
- **Testing**: JUnit 5 (Focus on code coverage > 80%)
- **Modeling**: UML (Class, Sequence, and State diagrams)
- **IDE**: IntelliJ IDEA

## 🧠 Key Concepts Applied
- **SOLID Principles**: Single Responsibility, Open/Closed.
- **Design Patterns**: Observer, State, Strategy.
- **Defensive Programming**: Equals/hashCode contracts, Custom Iterators, and Exception handling.
